## 背景与痛点

Web 应用测试竞赛要求在有限时间内把业务规则写成稳定、可重复运行的自动化脚本，同时兼顾页面异步加载与表单边界断言。

## 核心做法与我的职责

- 搭建独立 Python 虚拟环境，跑通官方表单提交、结果核对与自动截图基础链路。
- 针对 2025 年省赛历史练习样例编写并运行 `27` 条测试脚本，实测 `26` 条通过，精准定位出上海门店分支下的 `1` 条异常记录并保存截图与 JSON 运行报告。

- **已验证**：本地 Selenium 环境、官方入门样例闭环及 `27` 条历史题库脚本本地运行。

## 背景与痛点

机器人教学实验课上，初学者最常困惑的现象是“电脑和小车串口还连着，但小车突然冲出黑线”。很多同学只看连接指示灯绿着，误以为传感器也工作正常，忽略了数据早已停更。

## 核心做法与我的职责

按开放原子“开源基础软件与解决方案”赛道独立完成代码、说明文档与演示交付：

- **零依赖开箱即用**：仅依赖 Python 标准库（`python app.py --open` 或 Windows 脚本一键启动本地 `127.0.0.1:8788`），降低实训室电脑环境配置门槛。
- **两层分离检查与白话步骤**：明确区分“主控连接状态”与“巡线读数距今时长（如已 4.6 秒未更新）”，给出可执行的下一步核对清单并记录数据恢复节点。
- **快照序列逐帧回放**：支持载入多帧序列样本，逐步对比异常前后的字段变化并生成排查报告。
